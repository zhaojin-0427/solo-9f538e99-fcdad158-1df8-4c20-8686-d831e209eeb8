# 坡道标注核查平台

同一批道路影像由不同标注员判读坡道，本系统供质检员核对两人判读口径：
按标注员上传 CSV，任选两人计算四种配对计数与 Cohen's κ，并下载分歧清单。

## 启动

```bash
docker compose up --build
```

访问 http://localhost:8000 。SQLite 数据保存在名为 `qcdata` 的卷中。

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt
python app.py
```

## CSV 格式

UTF-8 编码，每行 `图号,标记`，首行可为表头：

```csv
图号,标记
1,有坡道
2,无坡道
3,看不清
```

- 图号：1～60000 的整数。
- 标记：`有坡道` / `无坡道` / `看不清` 三者之一。
- 同一 CSV 内同图多次出现时，以最后一行为准。

## 规则说明

- **原始标注与更正**：SQLite 保存原始标注；同人同图重复上传视为更正，
  只更新本人汇总，原始标注与汇总在同一事务中生效。
- **汇总**：每位标注员一份 2 bit/图 的压缩汇总（固定 15000 字节，
  上限 128 KiB）；核查只读汇总，查询时才选配对。
- **配对**：仅双方都判读为「有坡道/无坡道」的图参与配对（「看不清」
  与未标注不计入），输出四格计数（双方有 / A 有 B 无 / A 无 B 有 /
  双方无）与 Cohen's κ；没有有效配对或 κ 分母为零时提示无法比较。
- **一致性**：上传失败沿用原数据；数据库开启 WAL，上传期间仍可核查；
  一次核查的计数与分歧清单取自同一已提交状态（单读事务读取，
  分歧清单下载按汇总版本号校验，数据已更新时需重新核查）。
- **分歧清单**：CSV 下载，含分歧图号与双方判读，供抽查。
